Spot

Equipment-mounted gym rep counter. Personal project, started October 2026.

A small motion-sensing pod that mounts on the end of a dumbbell and counts reps from how the weight moves, built because my fitness watch kept miscounting.

  • Seeed XIAO nRF52840 Sense streaming 6-axis IMU data over I2C at 100 Hz, logged through UART to a Python tool.
  • Counting errors cut from 6 to 2 across 50 labeled dumbbell curls in 7 recorded sets, by adding a swept-angle check that rejects handling motion.
  • Every requirement has a number and a pass or fail test, scored against video.

VaultLink

Wi-Fi connected keypad lock box. Microcontroller Architecture course project, team of 2.

A multi-user electronic lock box on an STM32F401RE, programmed entirely in ARM assembly, that reports unlocks and tamper alarms to a phone.

  • 4x4 keypad, 16x2 LCD and a servo-driven latch around an 8-state lock controller.
  • 8 hashed user PINs, a lockout that doubles after 3 wrong entries, and an interrupt-driven tamper alarm.
  • UART link to a Wi-Fi module for phone alerts, built so the lock works fully without it.

PWM DC motor controller on FPGA

Digital Electronics course project at Texas A&M.

A DC motor speed controller built from flip-flops, counters and comparators, with no microcontroller, and run on an Intel DE10-Lite FPGA.

  • 7-state one-hot Moore state machine from 7 D flip-flops and gate-level logic, stepping motor speed from 0% to 90% duty cycle in 15% increments with 2 pushbuttons.
  • PWM generator from 74161 counters and 7485 magnitude comparators driving an external H-bridge, with a 50 to 100 kHz clock divider and a 2-digit 7-segment speed display.
  • State transitions verified in Quartus waveform simulation, then all 7 speeds and a 2-button full-speed override demonstrated on a DC motor.
